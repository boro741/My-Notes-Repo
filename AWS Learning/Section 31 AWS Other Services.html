1 AWS SES

SES (Simple Email Service) lets you send email using either an SMTP interface or the AWS SDK, and also receive email — with incoming mail integrating into S3, SNS, or Lambda for further processing. Access is controlled through ordinary IAM permissions.

Exam point SES = email. If a question is about sending or receiving email, SES is likely the answer; if it isn't about email at all, it almost certainly isn't SES.

2 Amazon OpenSearch Service

OpenSearch is the successor to Amazon Elasticsearch (renamed for licensing reasons). Unlike DynamoDB, which you can only query by primary key or an index, OpenSearch lets you search any field, including partial matches — so it's commonly used as a search layer alongside another database, not as your primary data store. It also supports analytics queries on the same data, visualized through OpenSearch Dashboards.

  • Two provisioning modes: a managed cluster (you see and manage the actual instances) or serverless (AWS handles scaling and operations entirely).
  • Has its own query language; SQL is only available via a plugin.
  • Ingests data from Kinesis Data Firehose, IoT, CloudWatch Logs, or a custom application.
  • Security via Cognito + IAM integration, with encryption at rest and in flight.

A common pattern: DynamoDB stays the source of truth, while OpenSearch (kept in sync via Streams + Lambda) provides fast partial-match search back to the item's ID.

Other ingestion patterns

  • CloudWatch Logs → a subscription filter feeding a Lambda function in real time, or feeding Kinesis Data Firehose in near real time — either way, landing in OpenSearch.
  • Kinesis Data Streams → either Kinesis Data Firehose (near real time, optional Lambda transform) or a custom Lambda consumer (real time) — both writing into OpenSearch.

3 Amazon Athena

Athena is a serverless query service (built on Presto) for analyzing data that lives directly in S3, using standard SQL — no data movement, no database to provision. Supports CSV, JSON, ORC, Avro, and Parquet. Pricing is a fixed amount per terabyte of data scanned. Commonly paired with Amazon QuickSight for dashboards (QuickSight → Athena → S3).

Use cases: ad hoc queries, business intelligence, analytics/reporting, and analyzing AWS service logs (VPC flow logs, load balancer logs, CloudTrail trails).

Performance tips (exam-relevant)

  • Use a columnar format (Parquet or ORC) — since you pay per TB scanned, only reading the columns you need saves money. Use Glue ETL jobs to convert other formats (e.g. CSV) into Parquet/ORC.
  • Compress your data so there's less to scan.
  • Partition your data by folder structure — e.g. year=1991/month=01/day=01/ — so a query filtering on year/month/day only scans the matching folders instead of the whole dataset.
  • Use bigger files (128 MB+) rather than many small ones, to cut down scanning overhead.

Federated Query

Athena can also query outside S3 — relational/non-relational databases, custom data sources, on AWS or on-premises — through a Data Source Connector: one Lambda function per source.

Federated Query reaches beyond S3 into relational, non-relational, and on-premises sources through per-source Lambda connectors, then combines the results.

Hands-on

Set an S3 location for query results, create a database, then a table pointing at an S3 prefix (e.g. access logs), preview the data, and run aggregate SQL — e.g. counting requests grouped by HTTP status and URI, or filtering for 403/404 responses to spot anomalies like unauthorized access attempts.

4 Amazon MSK

Amazon MSK (Managed Streaming for Apache Kafka) gives you a fully managed Kafka cluster — Kafka being an alternative to Kinesis for streaming data. MSK provisions and manages the Kafka broker and Zookeeper nodes across up to 3 AZs in your VPC for high availability, with automatic recovery from common failures; data is stored on EBS for as long as you want (even beyond a year, as long as you pay for the storage). MSK Serverless removes capacity planning entirely — AWS scales compute and storage for you.

Producers write to a Kafka topic (replicated across brokers); consumers pull from it — conceptually similar to Kinesis's shards, but called partitions.

Consuming from MSK: Kinesis Data Analytics for Apache Flink, Glue streaming ETL jobs (powered by Spark Streaming), Lambda (with MSK as an event source), or your own Kafka consumer running on EC2, ECS, or EKS.

5 AWS Certificate Manager (ACM)

ACM provisions, manages, and deploys SSL/TLS certificates — used to add in-flight encryption (HTTPS) to your endpoints. Supports both public and private certificates; public certificates are free, and ACM handles automatic renewal. It integrates directly with load balancers, CloudFront distributions, and API Gateway, which load the certificate and handle TLS termination for you.

ACM loads a TLS certificate onto the load balancer, which then terminates HTTPS from clients while still talking plain HTTP to the backend.

Exam point Anytime a question is about provisioning/renewing certificates or enabling HTTPS on an AWS-managed endpoint, think ACM.

Hands-on

Request a public certificate for a domain hosted in Route 53, validate it via DNS validation (ACM can auto-create the required Route 53 record), then attach the issued certificate to an Elastic Beanstalk environment's load balancer — add an HTTPS:443 listener, pick the ACM certificate and a TLS policy. Finally, create a Route 53 CNAME pointing your custom domain at the environment's URL. No security group changes were needed; the ALB's listener rules in the EC2 console confirm the certificate is loaded from ACM.

6 ACM Private CA

Beyond public certificates, ACM can also issue private certificates through an AWS Private Certificate Authority — a managed service where you create a root CA (and optionally subordinate CAs beneath it) to issue end-entity X.509 certificates for your own applications.

A private CA hierarchy issues certificates trusted only within your organization — they cannot be deployed on the public internet.

  • These certificates can still be loaded onto AWS services with ACM integration (load balancers, CloudFront, API Gateway, Kubernetes services), just like public ones.
  • Use cases: internal TLS communication, cryptographically signing code, authenticating users/computers/API endpoints/IoT devices, or building an enterprise public key infrastructure (PKI).

7 Amazon Macie

Macie is a fully managed data security and privacy service that uses machine learning and pattern matching to discover and protect sensitive data in AWS — most notably PII (personally identifiable information) sitting in your S3 buckets.

  • Point Macie at the S3 buckets you want scanned — enabling it is essentially one click.
  • Discoveries are surfaced through EventBridge, which you can route onward to an SNS topic, a Lambda function, or anywhere else for alerting and automation.

8 AWS AppConfig

AppConfig lets you configure, validate, and dynamically deploy configuration into your applications — completely independent of a code deployment, and without restarting the app.

The classic use case is feature flags: ship your application with a new feature turned off (false in AppConfig), and later flip it on — the running application picks up the change automatically. The same mechanism works for tuning performance parameters, IP allow/block lists, or any other config an app needs to read at runtime. Works with apps on EC2, Lambda, ECS, and EKS.

Configuration can roll out gradually across instances instead of all at once, with a CloudWatch alarm able to trigger an automatic rollback if something looks wrong.

Before deployment, a configuration can be validated using a JSON Schema (checking types/structure) or a Lambda function (for more complex custom validation logic).

✓ Cheat Sheet

Key facts to remember

  • SES sends and receives email (SMTP or SDK), integrating with S3/SNS/Lambda for incoming mail.
  • OpenSearch adds full/partial-field search and analytics on top of another database (commonly DynamoDB via Streams + Lambda); managed cluster or serverless.
  • Athena runs serverless SQL (Presto) directly over S3 data, billed per TB scanned; speed it up with columnar formats (Parquet/ORC), compression, partitioning, and larger files; Federated Query reaches non-S3 sources via per-source Lambda connectors.
  • MSK is managed Apache Kafka — an alternative to Kinesis — with brokers/Zookeeper across up to 3 AZs; MSK Serverless removes all capacity planning.
  • ACM provisions, auto-renews, and deploys public or private TLS certificates, integrating directly with ALB/NLB, CloudFront, and API Gateway.
  • ACM Private CA builds your own root/subordinate CA hierarchy for certificates that are trusted only internally, never on the public internet.
  • Macie uses ML to find PII/sensitive data in S3 and reports findings through EventBridge.
  • AppConfig dynamically deploys and validates application configuration (e.g. feature flags), with gradual rollout and CloudWatch-triggered rollback.

Mental model

This section is a grab-bag of services that each solve one narrow, well-defined problem: SES for email, OpenSearch for search layered on top of another database, Athena for ad hoc SQL directly on your S3 data lake, MSK for teams already committed to Kafka, ACM (and its private CA) for TLS certificate lifecycle management, Macie for finding sensitive data you didn't know was exposed, and AppConfig for changing application behavior without a redeploy. None of them need deep expertise for the exam — just enough to recognize which keyword in a question points to which service.
